# Stockhausen\-Goethe

A generative audiovisual experiment inspired by the music of Karlheinz Stockhausen, Goethe's theory of colors, stochastic processes, and octagonal geometry.

## Overview

Stockhausen\-Goethe explores the intersection of music, mathematics, color theory, and visual architecture through real\-time 3D graphics built with Three.js.

The project transforms concepts from:

- Karlheinz Stockhausen's spatial music
- Stochastic composition
- Goethe's Theory of Colours
- Geometric abstraction
- Generative art
- Procedural animation

into an evolving visual environment composed of octagonal structures, particle fields, harmonic motion, and dynamic color transformations.

## Concept

The project aims to build a virtual audiovisual instrument where:

- Geometry represents musical structure.
- Color represents energetic and emotional states.
- Motion represents temporal musical processes.
- Space becomes a compositional dimension.

The long\-term goal is to create a living visual architecture influenced by works such as:

- Gruppen
- Kontakte
- Licht

and by Goethe's principles of chromatic polarity.
